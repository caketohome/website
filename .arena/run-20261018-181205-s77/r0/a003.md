### 1. Resolution of Open Questions
1. **Open Question 1: Are historical financial discrepancies (Accounts 1114, 1122, 1121) current bugs to be patched?**
   - *Resolution:* No. They represent preserved historical states. Account 1114 (-₹200.00) requires an authorized ₹2,000 float voucher. Account 1122 (-₹2,450.00) requires an authorized ₹2,450 catch-up adjustment. Account 1121 (+₹2,000.00) reconciles 100% to historical SoD test vouchers. No automatic adjustments can be made without written Finance Controller approval.
2. **Open Question 2: How do we test live Next.js App Router without crashing on Windows git bug?**
   - *Resolution:* Windows `git.exe` in `C:\Program Files\Git\bin\git.exe` triggers fork bomb crashes. All git checks must use `C:\Program Files\Git\mingw64\bin\git.exe` with UTF-8 encoding.
3. **Open Question 3: How should bakery perishable products vs stocked inventory be verified?**
   - *Resolution:* Enforce strict distinction: cakes (`merchandise_type='CAKE'`) depend on kitchen slots/readiness, not inventory decrement. Accessories (`merchandise_type='ACCESSORY'`) use atomic row-decrement in `branch_inventory`.
