# CakeToHome ERP — Complete System-Wide Audit Architecture & Verification Strategy
## Candidate a004: Hard Constraints + Restructured Pillars + Edge Cases First

### 1. Hard Operating Constraints
1. **Zero Data Destruction:** Target environment is a live Supabase PostgreSQL database. Destructive drops, broad re-seeds, `git reset --hard`, and unapproved deletions are strictly barred.
2. **Finance Controller Gate:** No historical accounting entries (Accounts 1111, 1114, 1121, 1122, prototype invoices) may be altered without signed authorization.
3. **No External Side Effects:** No live SMS, WhatsApp, payment charges, or external courier webhook dispatches allowed.
4. **Environment Stability:** Windows shell must use `mingw64/bin/git.exe` and handle UTF-8 encodings cleanly to avoid process termination.

### 2. Edge Cases & Hostile Failure Modes First
1. **Cash Drawer Overdraft Attack:** When drawer contains ₹1,000, two concurrent expense disbursement requests for ₹700 and ₹600 must not both succeed. The database row-level lock (`FOR UPDATE`) must reject the second request with HTTP 422.
2. **Cross-Branch Data Leakage:** A Branch Manager from Koramangala attempting to view or acknowledge an Indiranagar cash drawer or delivery handover must receive HTTP 403 Forbidden.
3. **Statutory Tax Failure:** Any order containing a product or variant without an active tax rule in `public.tax_rate` / `public.tax_rate_rule` must fail closed (`TaxResolutionError: MISSING_TAX_RATE`), preventing legally invalid invoices.
4. **Segregation of Duties Bypass:** A voucher creator attempting to approve or post their own journal voucher must be blocked at both domain service and database check constraint levels.
5. **Duplicate Payment & Delivery Callbacks:** Repeated delivery completion or payment webhook events must return idempotent acknowledgements without generating duplicate invoices or journal lines.

### 3. Restructured Audit Framework
- **Pillar 1: RBAC & Multi-Role Boundary Testing:** Audit Platform Owner, Admin, Finance, Branch Manager, Branch Staff, Customer, Delivery Partner, Planner, and Suppliers for privilege escalation, session revocation, and data isolation.
- **Pillar 2: Playwright UI Automation:** Verify all routes and user-facing controls on Chromium across Desktop, Tablet, and Mobile viewports with zero uncaught console errors.
- **Pillar 3: Canonical Financial & Subledger Integrity:** Reconcile Trial Balance (₹14,925.00), verify Cash in Hand (+₹4,675.00), Petty Cash (-₹200.00), Undeposited COD (-₹2,450.00), and AR subledger (₹2,000.00).
- **Pillar 4: Domain Service & Persistence Proof:** Trace Browser -> API -> Domain Service -> Repository -> PostgreSQL for every transactional flow.
- **Pillar 5: Release Readiness Gate Assessment:** Evaluate Gates 1-14, maintain deployment block pending Finance Controller approval.
