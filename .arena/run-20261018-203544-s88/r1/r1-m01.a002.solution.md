# Revised Solution a002: Enterprise-Grade Forensic Audit & Completeness Matrix

## 1. Concrete Architecture & Collision Prevention
- Next.js 14 App Router on `http://localhost:3001` (PID 12560).
- Directory collision between `src/app/api/v1/admin/` and dynamic catch-all resolved via dedicated admin catch-all `src/app/api/v1/admin/[...path]/route.ts`.
- Database nuances: `public.branch` has no direct `state` column. Branch queries join `public.city c ON c.id = branch.city_id`.

3. **Inventory Manager**: Stock adjustments, reorders, batches (`/dashboard?tab=inventory`).
4. **Delivery Driver**: Task dispatch, GPS, proof upload (`/dashboard/delivery-partner`).
5. **Shop Manager**: Product acceptance, order prep (`/dashboard/shop`).
6. **Finance Manager**: General ledger, accounts, tax reports (`/dashboard?tab=accounting`).
7. **Customer Support**: Ticket resolution, customer logs (`/dashboard?tab=support`).
8. **Customer**: Storefront browsing, cart, checkout (`/checkout`).
9. **Guest**: Browsing, adding to cart, authentication enforcement on checkout.
