# Proposal a004: Evidence-First & Minimal-Moving-Parts Safeguard

## 1. Concrete Code Defects Identified
- Defect 1: Lines 398-401 of `DeliveryInvoicingService` swallow database errors.
- Defect 2: Missing format validation on `prefix`.
- Defect 3: Fallback to `"CTH"` can silently select conflicting prefix.

## 2. Minimal Remediation Diff
1. Validate `cleanPrefix`. If invalid/empty, return `INVOICE_PREFIX_INVALID`.
2. Check `invoice_sequence`. If conflicting GSTIN found, return `INVOICE_SERIES_PREFIX_CONFLICT`.
3. If database query fails, return `INVOICE_SEQUENCE_VERIFICATION_FAILED` immediately.
4. If stored function throws `AMBIGUOUS_GSTIN_SEQUENCE_SCOPE`, map to `INVOICE_SERIES_PREFIX_CONFLICT`.
5. Preserve order and payment status in all failure modes.
