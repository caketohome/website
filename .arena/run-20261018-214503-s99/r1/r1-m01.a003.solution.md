## 1. Sub-Problem Decomposition & Seam Analysis
We decompose this enterprise ERP challenge into five strictly bounded sub-problems:
- **Sub-Problem 1: App Router & Route Registry Integrity** (Entry seam: Next.js routing, middleware route guards, proxy rewrites, dynamic segment parsing).
- **Sub-Problem 2: UI Control Interactivity & State Binding** (Client seam: React component event handlers, optimistic mutation, rollback, multi-viewport layout validation).
- **Sub-Problem 3: Multi-Role Authorization & Isolation** (Security seam: Cookie session tokens, role claims, branch tenancy scoping, API route protection).
- **Sub-Problem 4: Relational Database Synchronization** (Data seam: PostgreSQL foreign key constraints, join conditions, schema indexes, transactional boundaries).
- **Sub-Problem 5: Financial Equilibrium & Invariant Protection** (Audit seam: Double-entry ledger reconciliation, Tax Master immutability, cash custody settlement).
