# Production Activation Runbook
**Prerequisite:** OUTCOME 1 resolved by formal Board Resolution  

## Activation Steps
1. **Intake Board Resolution:** Upload certified Board Resolution into Evidence Registry (`EVD-RES-01`).
2. **Verify Dual-Control:** Independent Director verifies resolution authenticity.
3. **Transition Decisions:** Transition BDR-01 through BDR-05 to `APPROVED`.
4. **Configure Series:** Finance Operator configures statutory series (e.g. `CTHI`, FY `26-27`, 5 digits).
5. **Approve Series:** Finance Approver approves series configuration.
6. **Re-evaluate Gate:** Run release gate evaluation; verify gate transitions to `READY_FOR_AUTHORIZATION`.
7. **Controlled Activation:** Authorized Release Manager triggers activation; series transitions to `ACTIVATED`.
