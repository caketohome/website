# Invoice Allocation Event Audit

## 1. Allocation Log Architecture
The `public.invoice_allocation_log` table records atomic sequence requests generated by `allocate_invoice_number_atomic()`.

## 2. Audit of the 8 Allocation-Only Positions
The 8 allocation-only entries (positions 4, 6, 7, 9, 10, 11, 12, 13) were generated during automated race-condition concurrency testing:
- **Order IDs:** `ord_concurrent_1` through `ord_concurrent_10`
- **Status:** `ALLOCATED`
- **Database Context:** The allocation transaction committed in the autonomous logging block, while the parent order-invoicing transaction deliberately aborted to test isolation.
- **Audit Conclusion:** Verified as expected behaviour of autonomous sequence logging under transactional rollback.
